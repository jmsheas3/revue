# ⌨️ Keyboard shortcuts

Press `?` in revue (or click the `?` button in the header) to see these at any time.

## 💻 In a repo

| Keys | What they do |
|---|---|
| `j` `k` (or `n` `p`) | Next / previous changed file |
| `Esc` | Back to all changes |
| `/` | Filter files |
| Ctrl+click (⌘+click) | [Go to definition](features.md#-go-to-definition) (browser Back returns) |
| `f` | Diff → file → preview (markdown) or image (SVG) |
| `s` | Split / unified |
| `w` | Wrap long lines / scroll sideways |
| `1` `2` `3` | Changes / History / Branch |
| `r` | Refresh |
| `?` | Show or hide the shortcut list |

Split needs room: when it doesn't fit, diffs are unified (see [Diffs](features.md#-diffs)).

## 🌳 In the file tree and the commit list

| Keys | What they do |
|---|---|
| `Tab` | Move into the list |
| `↑` `↓` | Previous / next row |
| `→` | Open a folder |
| `←` | Close a folder; on a file or a closed folder, move up to its parent folder |
| `Home` `End` | First / last row |
| `Enter` `Space` | Open the row |

## 📁 In a plain folder

[Plain folders](plain-folders.md) have no modes or diffs, so a few keys change:

| Keys | What they do |
|---|---|
| `j` `k` (or `n` `p`) | Next / previous file in the tree |
| `Esc` | Back to the folder's README |
| `f` | A markdown or SVG file: file view ↔ preview or image |
| `Enter` `Space` in the tree | Open the row; on a folder, also show its README |
| Ctrl+click (⌘+click) | Go to a definition among the folder's files |
| `w` `/` `r` `?` | As in a repo |
| `s` `1` `2` `3` | Nothing |
